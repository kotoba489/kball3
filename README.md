## 　kball3ファームウェア構築

. 概要
本メモは、自作トラックボールキーボード「**kball3**」（最新基板 `kball3.kicad_pcb` 準拠）における ZMK ファームウェアの構築仕様、ピン割り当て、カスタムレイヤー構成（コンボ機能・Bluetooth切替含む）、Bluetooth 接続安定化対策、および将来の ZMK バージョンアップ手順についてまとめた保存用記録です。

- **GitHub リポジトリ**: `https://github.com/kotoba489/kball3`
- **使用 MCU**: Seeed Studio XIAO nRF52840 (`seeeduino_xiao_ble`)
- **使用 センサー**: PMW3610 ブレイクアウト基板（PMW3610 + レンズ付き, JP1 ジャンパ 1-2 ショート VIO=VIN）
- **キー構成**: 3 ボタン（縦並び配置） + 光学式トラックボール

## 2. ハードウェア配線およびレイヤーキーマップ仕様

`kball3.kicad_pcb` のパターンレイアウトに基づき、MCU（XIAO nRF52840）への全ピン割り当て（3個のスイッチボタンおよび PMW3610 センサー）と、多層レイヤー構成を以下のように定義しています。

### 2.1 スイッチボタンのピン割当 & レイヤー機能表

| ボタン位置       | XIAO ピン名   | MCU 内部ピン | 信号種別        | Layer 0 (デフォルト)       | Layer 1 (矢印キー)        | Layer 2 (コンボ 1+2)              | Layer 3 (コンボ 2+3)              |
| :---------- | :--------- | :------- | :---------- | :-------------------- | :-------------------- | :----------------------------- | :----------------------------- |
| **1番目 (上)** | Pad 2 / D1 | `P0.03`  | Direct GPIO | 右クリック (`&mkp RCLK`)   | 右矢印 (`&kp RIGHT`)     | BT情報全消去 (`&bt BT_CLR_ALL`)     | BTプロファイル 1 選択 (`&bt BT_SEL 1`) |
| **2番目 (中)** | Pad 3 / D2 | `P0.28`  | Direct GPIO | 左クリック (`&mkp LCLK`)   | 左矢印 (`&kp LEFT`)      | BTプロファイル 0 選択 (`&bt BT_SEL 0`) | BTプロファイル 2選択 (`&bt BT_SEL 3`)  |
| **3番目 (下)** | Pad 4 / D3 | `P0.29`  | Direct GPIO | Layer 1 へ移行 (`&to 1`) | Layer 0 へ復帰 (`&to 0`) | Layer 0 へ復帰 (`&to 0`)          | Layer 0 へ復帰 (`&to 0`)          |

#### コンボ（同時押し）操作仕様
- **L2 コンボ** (ボタン 1 + ボタン 2 同時押し) ➔ **Layer 2 へ移行** (`&to 2`：Bluetooth プロファイル 0 選択 / ペアリング全消去)
- **L3 コンボ** (ボタン 2 + ボタン 3 同時押し) ➔ **Layer 3 へ移行** (`&to 3`：Bluetooth プロファイル 1 & 3 選択)

---

### 2.2 PMW3610 トラックボールセンサーのピン割り当て表

| センサー信号 | XIAO ピン名 | MCU 内部ピン | 信号種別 | 役割 / 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **SCLK** | Pad 6 / D5 | `P0.05` | SPI Clock | PMW3610 クロック信号 (`spi0_default`) |
| **SDIO** | Pad 5 / D4 | `P0.04` | SPI MOSI / MISO | PMW3610 データ信号（3線式双方向通信） |
| **nCS** | Pad 8 / D7 | `P1.12` | GPIO (Active Low) | PMW3610 チップセレクト (`cs-gpios`) |
| **MOTION** | Pad 11 / D10 | `P1.15` | GPIO (IRQ) | PMW3610 モーション検出割り込み (`irq-gpios`) |
| **VCC** | Pad 12 | `3V3` | Power Supply | 3.3V 電源供給 (JP1 1-2 ショート VIO=VIN) |
| **GND** | Pad 13 | `GND` | Ground | グランド |

## 4. Bluetooth 再接続安定化設定 (`kball3.conf`)

Mac や Android スマホで「電源スイッチを OFF から ON に戻した際に自動接続されず、ペアリング解除操作が必要になる現象」を回避するための最適化設定です。

```properties
# ---------------------------------------------------------
# 1. トラックボール・ポインティング設定 (ZMK v0.3.0 対応)
# ---------------------------------------------------------
CONFIG_SPI=y
CONFIG_INPUT=y
CONFIG_ZMK_POINTING=y
CONFIG_PMW3610=y

# ---------------------------------------------------------
# 2. Bluetooth 接続安定化・電波強度設定（macOS / Mobile 対応）
# ---------------------------------------------------------
# 送信電波強度の最大化 (+8dBm)
CONFIG_BT_CTLR_TX_PWR_PLUS_8=y

# 実験的 BLE 接続改善（高速自動再接続アルゴリズム）
CONFIG_ZMK_BLE_EXPERIMENTAL_CONN=y

# macOS に最適化した BLE 接続インターバル設定 (7.5ms ~ 15ms)
CONFIG_BT_PERIPHERAL_PREF_MIN_INT=6
CONFIG_BT_PERIPHERAL_PREF_MAX_INT=12
CONFIG_BT_PERIPHERAL_PREF_LATENCY=0
CONFIG_BT_PERIPHERAL_PREF_TIMEOUT=400

# ---------------------------------------------------------
# 3. 電源管理（スリープ設定）
# ---------------------------------------------------------
# 深いスリープ（Deep Sleep）からの復帰時のBLE不整合を回避するため無効化
# （使用しない時は物理電源スイッチでOFFにする運用）
CONFIG_ZMK_SLEEP=n
```

## 5. ZMK のバージョンアップと将来のメンテナンスについて

### 現状のバージョン整合性
- **ZMK 本体**: **`v0.3.0`** (`revision: v0.3.0`)
- **センサードライバ**: **`badjeff/zmk-pmw3610-driver`** の **`zmk-0.3` ブランチ** (`revision: zmk-0.3`)

センサードライバ作者（badjeff 氏）によって ZMK `v0.3.0` 専用の修正ブランチ（`zmk-0.3`）が用意されており、両者の規格が100%合致した状態で稼働しています。
### バージョンアップについては以下を参照しました

https://github.com/snize/zmk-keyboard-suzuri

テンプレートも公開されています
https://github.com/snize/zmk-suzuri-config-template

### 将来 ZMK をバージョンアップする際の手順（例: `v0.4.0` や最新安定版へ移行時）
将来、ZMK 公式およびドライバが新しいバージョンへ移行した場合は、以下の2箇所のファイルを更新して GitHub へプッシュします。

1. **`config/west.yml` の変更**:
   ```yaml
   projects:
     - name: zmk
       remote: zmkfirmware
       revision: v0.4.0  # ← 新バージョンに変更
       import: app/west.yml
     - name: zmk-pmw3610-driver
       remote: badjeff
       revision: zmk-0.4 # ← 対応するドライバブランチに変更
   ```
2. **`.github/workflows/build.yml` の変更**:
   ```yaml
   jobs:
     build:
       uses: zmkfirmware/zmk/.github/workflows/build-user-config.yml@v0.4.0  # ← リビジョンを合わせる
   ```

## 6. トラックボール受け皿（3Dプリント用 STL モデル）の修正履歴

物理構造上の干渉や組み立て性を改善するため、トラックボール受け皿（球径 25 mm / 支持球 1.5 mm × 3点）の 3D データを以下のように修正・更新しています。

### 3D モデルファイルの概要

- **ソース格納先**: `Desktop/TB_pcb/3D/` およびプロジェクト内 `3D/`
- **対象モデル**: 25 mm球トラックボールホルダー

### 修正プロセスと各バージョンの特徴

1. **`trackball_25mm_receiver_v3_closed_pedestal.stl` (ベースモデル)**
   - センサー基板の収容スペースは完全にフラット。
   - 配線用スリット（6本のジャンパー線用）の出口下部に **0.4 mm のわずかな下部リップ（突起段差）** が残っており、配線を引き抜く際にメインPCB側と干渉する要因になっていた。

2. **`trackball_25mm_receiver_v4_flat_base.stl` (修正モデル)**
   - `v3` の基本形状（センサー空間など）は完全に維持したまま、配線用スリットの出口下部にある 0.4 mm のリップ部分のみを削り落とし、メインPCBとの接地底面が真っ平らになるように修正したモデル。

3. **`trackball_25mm_receiver_v5_exit_lip_cut.stl` (中間修正モデル)**
   - `v3` の原型をベースに、より正確な切削サイズ（幅 11 mm、カット座標調整）で 0.4 mm リップ部を抜く加工を行ったバージョン。センサー基板収納の天井や他の外殻ジオメトリを変更せずに、配線の抜け性のみを確実に最適化したモデル。

4. **`trackball_25mm_receiver_v6.stl` (完全新規設計・初期モデル)**
   - **筐体サイズ制限への完全適合**: ボトムケースの収容凹みに完全にフィットするよう、台座の寸法を **横 36.5 mm × 縦 30.0 mm、角のフィレットを 0.5 mm** に固定。
   - **干渉の排除（凹みの廃止）**: センサー基板の天井面（Z = 6.7 mm）にあった不要な2箇所の小さな凹みを廃止し、完全に平らな天井面に設計変更。
   - **天板（ソリッドプレート）の形成**: 左右の耳（台座上面）が開口（吹き抜け）にならないよう、台座全体の高さを **7.5 mm** に調整し、センサーキャビティ（高さ 6.7 mm）の上に **0.8 mm の天板（クローズドプレート）** を形成して強度と美観を確保（ボトムケース内のPCB支持柱 7.5 mm と完全に高さを一致）。
   - **配線スリットの拡幅**: 6本のジャンパー線がスムーズに抜けられるよう、出口幅を **16.5 mm** に拡幅。底面のリップ段差を完全に除去し、底面から平らに接続。上部にはトンネル状に天板が残る設計。
   - **正確な光学距離の確保**: PMW3610 の推奨条件である「レンズ基準面〜スキャン面（ボール最下部）の距離 2.4 mm」を確保するため、ボール最下点を Z = 9.1 mm、レンズ突き当て面を Z = 6.7 mm に配置し、**2.4 mm のクリアランスを数学的に担保**。

5. **`trackball_25mm_receiver_v7.stl` (カップ深化＆支持球位置調整モデル)**
   - **カップの深化によるボールの安定化**: ボールが浅くて不安定に転がる現象を抑えるため、上面の高さを従来の 14.0 mm から **15.5 mm** に引き上げ、球体をより深くしっかりと包み込む形状に変更。
   - **支持球の配置変更（横ブレ防止）**: 3点の支持球（1.5 mm ジルコニア球）の接触角度を従来の 40度 から **45度** に広げ、支持球の Z位置を上方向（約 0.8 mm 上）に移動。これによりボールの赤道付近に近い位置で側面を支え、回転時の横ブレを大幅に低減。
   - **光学距離 2.4 mm の厳密な維持**: 支持球の配置変更に伴い、支持ポケットの位置を外径方向へ広げる数式調整を行い、ボール最下部（Z = 9.1 mm）およびレンズ基準面（Z = 6.7 mm）との距離はデータシート通り **ピッタリ 2.4 mm** を正確に維持。
   - **その他の仕様維持**: 外寸（横 36.5 × 縦 30.0 × 角R 0.5）、フラットなセンサー空間（高さ 6.7）、16.5 mmスリットは `v6` からそのまま継承。

   - **ベース底面外側の面取り（フィレット0.5mm）**: 台座の外壁と接地底面の角に **0.5 mm のフィレット（丸み）** を追加。これにより、ボトムケースへの接触がさらに滑らかになり、触り心地や見た目の美しさが向上。
   - **キャビティ底面内側の面取り（面取り0.5mm）**: センサー用キャビティ（基板を入れる空間）の入り口底面に **0.5 mm の 45度面取り（C面）** を追加。エレファントフットによるサポートとの合体を防ぎつつ、センサー基板の挿入をスムーズにガイドする設計。
   - **レンズ穴天井部の面取り（フィレット1.0mm）**: センサー用キャビティ天井からレンズへつながる 8.5 mm の円筒穴の底面エッジに **1.0 mm の大きなフィレット（喇叭状のフレア）** を追加。レンズを傷つけることなくぴったりフィットし、微小なゴミが溜まりにくい滑らかな構造に変更。

   - **天板の継承**: 耳の部分の **0.8 mm** の天板（ソリッドプレート）仕様を継承し、台座の高さは **7.5 mm**。

## 8. トッププレートのカバー方式（ザグリ加工）と物理設計の工夫

キーボード全体の低背化（薄型化）とスマートな美観を両立させるため、以下の物理設計と3Dプリントの工夫を行っています。

### 8.1 トップカバーと受け皿の取り合い（カバー方式）
- **美観重視の設計**: 受け皿のフチを露出させるツライチ（面一）仕上げではなく、トッププレートで受け皿のフチ（外径 30.0 mm）を覆い隠す「カバー方式」を採用。丸穴からボールだけが覗く、市販品のようなスマートな美観を実現。
- **ボトムケースの沈み込み構造**: ボトムケースの台座受け部分をあらかじめ **`1 mm 深く設計（沈み込み）`** 。これにより受け皿全体が下がり、トップカバーとの干渉防止クリアランスを自動的に確保。
- **トップカバー裏のザグリ（逃げ加工）**: 厚さ 2.0 mm のトップカバーの裏面に対し、**`直径 32 mm 、深さ 1.0 mm の円形ザグリ穴（凹み）`** を設けることで、受け皿との干渉を防ぎつつ、全体の高さをさらに **1.5 mm 低く（ボトムケース全体高さ 20.5 mm）抑えることに成功。
- **ボール露出用のアパチャ（穴）**: 表側の貫通穴は **`25.5 mm 〜 26.0 mm`** に設定し、ボール（25.0 mm）を上から簡単に取り出して支持球（ジルコニア球）をメンテナンスできる仕様。

### 8.2 3Dプリント時のスライサー設定（Bambu Studio / OrcaSlicer）
- **天面上向き印刷の選択**: トップカバーの天面の美観（プレート接地側のザラつき防止、アイロニング適用など）を最優先するため、天面を上向きにして印刷。
- **サポートなしでのザグリ天井ブリッジ**:
  - ザグリ穴部分（直径 30.4 mm、深さ 1.0 mm）は、スライスすると幅約 **`2.2 mm`** の細い「同心円状のひさし（コンセントリック・ウォール）」として積層される。
  - スパン距離が非常に短く、かつ0.6mm沈み込みマージンがあるため、**サポート材を一切使用せず（サポート「オフ」）**に極めて平らで綺麗に印刷可能。
